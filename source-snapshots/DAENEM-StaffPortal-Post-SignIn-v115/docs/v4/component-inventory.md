# Component inventory

- Portal.tsx: route shell, session, permission gate, record mutations, dialogs and local audit.
- lab-context.tsx: stable shared provider/hook contract. Extracted to prevent a duplicate context during module refresh.
- model.ts / security-contract.ts: route registry, fixtures, projected fields and record scopes, capability checks and ten test profiles.
- auth-v3.tsx / auth-contract.ts: ten compositions, form stages, password/verification rules and world clocks.
- homes-v3.tsx / scenery-v3.tsx: ten home structures, permitted record metrics, photo headers and sidebar landscape.
- profile-v3.tsx / attendance-v3.tsx: profile self-service and attendance event simulation.
- table-v3.tsx: sorting, filtering, grouping, column control, views, pagination and export.
- enterprise-v3.tsx / enterprise-contract.ts: operational ledgers, safe builder definitions, local lifecycle and domain guards.
- workspaces.tsx / studios.tsx: retained operational pages and administration studios; review known domain-depth gaps.
- ui.tsx and components/ui: shared controls and Radix-based dialogs, forms and disclosure primitives.
- app/review/viewports/page.tsx: explicit CSS viewport workbench for permitted scenes.

Source inventory is an implementation map, not a declaration that all components satisfy the master contract.
