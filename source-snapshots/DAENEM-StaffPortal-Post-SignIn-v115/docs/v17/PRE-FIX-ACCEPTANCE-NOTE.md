# V17 pre-fix acceptance correction

The ten disputed V16 Sign-In and Builder requirements are corrected to **FAIL** before V17 implementation begins. V16 string-presence checks are not accepted as functional evidence. V17 may restore a requirement to `PASS_VERIFIED` only through runtime behavior, measured browser evidence, and synchronized screenshots from the final source.

Construction, Communications, Banking, Payroll and the remaining ERP are frozen for regression testing only.
